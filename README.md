# Node.js WebSocket Multiplayer Sample

A small real-time multiplayer technical sample built with Node.js and WebSockets.

## What I Implemented

- Node.js HTTP and WebSocket server
- Multiple simultaneous player connections
- Real-time synchronized player movement
- Shared server-side player state
- Player join and disconnect handling
- Player name updates
- WASD and arrow-key movement
- Server-side validation of player coordinates
- Browser client/server communication using JSON messages

## What I Debugged / Fixed

While testing the project, I worked through project startup/path issues and verified the Node/npm setup.

I also tested the multiplayer synchronization using multiple browser clients to confirm that connections, movement updates, and disconnect handling worked correctly.
